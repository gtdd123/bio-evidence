# BioEvidence 首版功能规格

版本：0.1.0  
日期：2026-10-08（Asia/Shanghai）  
状态：用户已于 2026-10-09 确认；Clarify 一致性检查通过，进入 Plan 阶段  
上游依据：已确认的《科研平台需求摘要》与 `BioEvidence_CONSTITUTION.md`

本文件定义首版的用户行为和验收契约，不规定内部框架、数据库、RPC 方法或模块拆分，也不代表这些功能已经实现。首版具体默认行为已随整体 Spec 获得用户确认，是后续 Plan 与 Tasks 的依据。

## 1. 目标与交付范围

BioEvidence 面向课题组科研人员，以可私有化的服务承载公开文献调研和受控实验资料管理。首版同时提供桌面与 Web，形成“公开文献 → 证据表 → 带引用报告”的完整流程，以及可验证的身份、项目和数据边界。

求职展示须能说明继承的 Craft 能力、本项目新增功能、实际验证结果与当前限制。细胞运动图像分类是使用背景；本次不建设视觉分类模型、训练系统、GPU 调度或本地语言模型服务。

首版新增业务包括：账号与项目成员授权、论文与证据管理、报告引用及修订状态、受控资料目录浏览、外发策略和上述功能的跨端使用。已有会话内核、模型适配和存储仍作为复用基础。

## 2. 术语与两种边界

| 术语 | 含义 |
| --- | --- |
| 个人空间 | 由一个账号拥有，默认仅该账号访问的资料、会话与产物范围 |
| 科研项目 | 有负责人和明确成员关系的协作范围；资源的项目归属不能由请求者自行伪造 |
| 公开资料 | 已从公开文献来源取得，或由有权限的导入者明确声明可发送外部模型的论文内容 |
| 私有资料 | 实验材料、未明确公开的导入文件、私有备注及其可追溯衍生内容 |
| 受控环境 | 用户或课题组控制的服务与资料所在机器，以及已授权用户的访问端；不包含外部模型、第三方分享或遥测服务 |
| 证据条目 | 对实际读取来源的一段事实或原文的结构化记录，带来源、定位、读取层级和修订状态 |
| 报告修订 | 一次可辨识的报告版本，引用确定的证据版本，记录生成或修改者与时间 |
| 运行记录 | 一次调研执行的状态、步骤、已完成产物及必要诊断信息 |

**访问权限和数据外发权限分别判断。** 个人空间里的公开论文可以用于云端调研；项目成员共享的实验材料仍然是私有资料。“公开资料”不意味着匿名用户可访问项目或报告。

来源不明的文件默认私有。修改标题、移动到共享项目、复制产物、清空界面选择或切换模型，均不能自动降低已记录的数据边界。平台内引用、复制和生成的衍生记录保留来源及其限制。

## 3. 首版用户与权限

首版采用课题组管理的账号：部署负责人初始化平台管理账号，再由管理账号创建、停用课题组账号；不发送邀请邮件，不开放匿名注册。普通账号可创建个人项目或共享项目，创建者为项目负责人。

平台管理权限用于账号和服务配置，不自动获得其他人的个人空间或项目数据读取权。项目负责人可管理该项目成员与资料入口，但目录登记只使用服务端事先授予自己或该项目的资料范围，不能因此取得新的磁盘访问权；资料范围的授予由部署侧依据资料拥有者授权建立并留痕，不能由客户端声明或普通项目负责人自授。成员可查看共享内容、创建项目内会话和科研产物，并修订共享证据与报告。成员不能管理成员关系或修改资料根目录。项目负责人在首版不可删除自身成员关系而留下无负责人项目。

| 操作 | 个人空间所有者 | 项目负责人 | 项目成员 | 非成员/未登录者 |
| --- | --- | --- | --- | --- |
| 读取资料、证据、报告、预览 | 允许 | 允许 | 允许 | 拒绝 |
| 创建会话与科研产物 | 允许 | 允许 | 允许 | 拒绝 |
| 执行或取消会话调研 | 仅自己的会话 | 仅自己的会话 | 仅自己的会话 | 拒绝 |
| 修订共享证据与报告 | 仅自己的空间 | 允许 | 允许 | 拒绝 |
| 增加/移除项目成员 | 不适用 | 允许 | 拒绝 | 拒绝 |
| 登记、移除资料入口 | 仅已被授予的资料范围 | 仅已被授予该项目的资料范围 | 拒绝 | 拒绝 |
| 订阅事件、下载允许的产物 | 允许 | 允许 | 允许 | 拒绝 |

会话归属与项目成员关系都须校验：项目成员可读取项目共享会话，但不能冒用他人的执行身份。退出登录、账号停用、登录状态到期及成员移除后，后续受影响请求和事件交付拒绝访问；客户端提示重新登录或权限变化。已经下载到用户设备的内容不能声称已被追回。

服务端资源读写、预览、导出和事件订阅都适用相同规则。可猜测标识、旧共享 token、客户端伪造身份或隐藏界面按钮均不能绕过授权。缺少归属信息的旧记录不自动向团队开放；需要明确归属后才能使用。

## 4. 代表性使用场景

1. 科研人员在桌面创建公开文献调研会话，输入“细胞运动与活细胞显微时序图像的 AI 分析方法”，检索并选取论文，生成证据表和报告；登录 Web 后继续查看、核对和修订同一份工作。
2. 负责人邀请一个已存在的课题组账号加入项目。该成员看到项目共享论文和报告，不能看到负责人的个人空间。成员移除后，后续读写和事件停止。
3. 负责人为项目注册受控服务能够访问的实验目录。成员按批浏览显微图片和连续帧，查看预览、文件信息和关键词匹配结果；平台不自动将这些内容附加到云端会话。
4. 文献服务、PDF 解析或模型请求失败。用户看到失败的具体步骤及已完成结果，可以重试；服务重启后能判断任务是否中断，不把旧进度显示为仍在运行或已完成。

## 5. 公开文献检索与导入

### 5.1 检索与选择

- 首版至少接入一个实际可用的公开文献服务，支持关键词检索、结果选择和继续获取下一批；具体服务在 Plan 中确定。
- 展示实际返回的标题、作者、年份、稳定标识及摘要/全文可用状态；缺失字段标为未提供，不补造 DOI、作者或年份。
- 只将用户选中的来源加入本次调研。没有结果时保留查询并显示空结果；服务失败、超时或限流时保留查询与已有结果，显示可重试状态。
- 在同一授权范围与数据策略内，按 DOI、PMID、PMCID 等已确认标识识别同一论文，保留来源关系；没有稳定标识时不仅因标题相似就自动合并。相同范围内重复导入不重复创建同一来源副本，冲突元数据保留并提示核对。去重不能跨个人空间复用私有记录、附带批注或借机降低资料限制。
- 全文取得依据来源与内容许可。取得失败时可保留题录和摘要，明确显示读取层级；不会把有全文链接等同于已经读取全文。

### 5.2 PDF 与私有导入

- 导入者须拥有目标空间/项目权限。PDF 默认私有；在公开论文导入流程中，导入者可明确声明其公开性质，平台记录声明者、时间和可核对的来源信息。
- 没有公开声明的 PDF 不进入外部模型或公开文献会话。公开声明不是自动解除既有私有记录的限制，也不声称平台能从正文自动判断所有敏感信息。
- 首版 PDF 上限为 25 MiB、100 页；超过上限不静默截断，提示当前限制并保持原有任务。上限可在后续经验证后调整。
- 可提取文本的 PDF 保留页码、已读取/未读取页及来源定位。纯扫描、加密、损坏或无法解析的文件显示具体状态，不伪造读取结果；混合文本/扫描 PDF 只保留成功读取部分并显示未读取页。首版不引入外部 OCR。
- 导入方式与读取范围分别记录：PDF 导入不自动等于读到论文全文；仅摘要的文件标为摘要，不完整或完整性未确认的文件标为部分文本。来源展示说明图像、表格和页面的读取缺口，不将文本提取等同于完成了图像/表格分析；生成记录保留本次实际使用的片段范围。
- 受控环境内的私有 PDF、TXT、Markdown 和 CSV 可作确定性文本解析与关键词检索，遵守配置的大小/解析预算；超限或不支持格式明确拒绝相应解析，保留资料入口。
- 移除来源不删除用户注册目录里的原文件；被现有证据引用的来源可停用，但其读取快照与引用关系仍供有权限用户核对。

## 6. 证据表与引用报告

### 6.1 证据记录

每条证据至少含：来源标识、取得方式、读取范围（摘要/全文/部分文本及覆盖信息）、来源版本或内容指纹、原文片段和页码/段落定位、事实摘要、局限或缺失信息、生成/修改者、修订号、核对状态。事实摘要与原文分开，不把模型改写当作逐字引文。

证据可以由模型提议或由用户手工录入。来源不存在、片段不能在读取内容中对应、定位不完整或元数据冲突时标为待核对；未提供的数字、样本量和方法保持缺失。

自动校验只能证明标识、片段与定位的一致性；不能声称已经证明结论科学正确或证据支持了该论断。人工审阅状态单独记录操作者、时间及对应修订。修改事实摘要、原文、定位、引用集合或报告结论产生新修订，新修订不继承旧版本的核对/审阅状态；可重新自动校验，但人工状态须重新确认。旧版本保留历史记录，不覆盖既有报告引用的证据版本。

### 6.2 报告与修订

- 报告显示研究问题、材料范围、读取层级、研究结论、证据局限及参考来源。每项研究结论须关联一条或多条证据；模型推断须明示为推断并给出依据。
- 报告状态区分草稿、引用待核对、引用校验通过和人工已审阅；引用校验通过不等同于科学审阅通过。
- 缺少来源、引用失效、证据片段不匹配或有未解决结构核对项时，可保存草稿，但不能标成引用校验通过或人工已审阅。结构校验通过后，仍由人工判断证据是否支持论断；例如引用真实的数据规模片段，却据此声称跨设备泛化，不能被自动判断为结论成立。用户可标为需要修改，再修订相应结论/证据。
- 报告绑定确定的证据修订。后续证据变化时，保留旧报告与旧审阅记录，并显著提示其依据已有新修订、需要重新核对；历史已审阅记录不作为新报告版本的当前审阅。更新报告产生新版本，重新校验/审阅，不自动覆盖用户文字。
- 首版支持页面查看、Markdown 报告和 CSV 证据表导出；导出包含来源和读取层级，保留当前状态。导出需授权，私有产物只下载给有权限用户，不上传第三方 viewer。
- 多端或多人同时修订时，过期修订不能覆盖较新版本；提示版本冲突，保留本地待提交文字供用户重新核对。
- 文件名、来源正文、Markdown 和模型输出作为数据展示，不执行其脚本、嵌入命令或公式，不自动加载其中的第三方跟踪资源。

## 7. 受控实验目录与连续帧浏览

- 资料入口引用受控服务实际可访问、且已经授予该账号或项目的目录，不要求复制大量文件。负责人只能在该预授权范围内登记，登记关系绑定空间/项目与数据策略；服务进程可读某个磁盘路径不等于该账号可登记它。
- 登记时拒绝未获授权的根、其他空间/项目的私有根及会造成越界访问的重叠父目录；平台凭据、账号存储、内部配置和状态目录不能登记为科研资料。确需共享同一物理目录时，须有独立且明确的资料授权，不能通过父路径或符号链接自授。
- 首版浏览与检索对实验原文件只读。平台自己的备注、索引或预览不得写入或改变实验原文件。
- 按指定目录层级浏览，默认每批 100 项，上限 200 项，提供继续读取方式。只因打开页面不能读取全部原图或无界递归解析下级目录。
- 显示文件名、类型、大小及可获取的图像信息；关键词检索范围为名称、已导入的备注/标签及预算内提取的文本，不声称能检索图像中的生物学含义。
- 首版预览覆盖 PNG、JPEG 和常见二维 TIFF。连续帧可按有序文件或普通多页 TIFF 的页进行前后浏览，显示名称和序号；不自动推断细胞身份、速度、时间间隔或分类标签。
- 缩略图最长边不超过 256 像素，单帧查看预览最长边不超过 2048 像素；界面说明其为浏览预览，原文件保持不变。不需要下载全部帧才能查看一帧。
- 解码预算必须配置并可测试。超预算、特殊 TIFF、未知格式、损坏图像、文件消失或目录离线时显示状态；不能因一个文件失败导致整个资料入口不可用。
- 实际路径、符号链接及文件打开均限定于已注册范围和授权资源；根目录外、未注册目录或其他项目路径拒绝访问。预览、原文件下载及索引访问采用同一授权。
- 未连接 4090 实验服务器时，显示该真实资料入口未接入；首版用合成目录验收入口功能，不能显示实际实验资料已浏览。真实服务器接入在有连接配置后另作验证。

## 8. 云端与私有数据策略

1. 公开文献调研发送范围限于用户明确公开的研究输入和已选中的公开来源/产物；界面显示本次连接及数据范围。私有备注、其他会话、资料目录及项目记忆不能自动注入公开请求。
2. 任何已选择的私有或未分类来源、已包含私有内容的会话历史或衍生产物，使该上下文不能发送外部模型；在发出请求前拒绝整次操作并说明需另建仅含公开资料的调研。
3. 公开会话的工具不能读取私有资源后再把结果交给云端。拒绝应发生在内容返回工具/模型之前；错误反馈与普通诊断不包含被拒绝的私有正文或路径。
4. 首版公开调研仅运行已登记、已授权的公开文献工具和公开产物操作；未受控的 shell、任意路径读取及未分类 MCP/API 工具不在其允许执行范围。保留上游接入基础，新增来源须明确权限、数据类别和出口。
5. 标题生成、摘要、压缩记忆、附件解析、工具请求、分享和遥测同样受策略约束；safe/ask/allow-all 不能绕过数据边界。来源和模型输出中的指令不能变成平台权限或数据策略变更。
6. 首版不部署可信本地语言模型。私有材料的 AI 推理返回“未配置可信本地模型”，保留资料并提供浏览/检索入口；官方或兼容接口都不因配置名称为“本地”就获得私有内容。
7. 官方 viewer 和第三方公开分享在首版关闭；已认证的项目共享及授权下载保留。前端隐藏和服务端拒绝都须落实，不能仅隐藏按钮。
8. 模型/来源密钥只通过后端配置使用，不向普通客户端返回明文，不写入客户端构建或示例。用户登录所需的会话凭据通过可信认证路径使用，不能混同为模型密钥，也不进入普通诊断或公开文件。日志、审计和错误中排除凭据、完整私有提示词及正文；授权浏览私有内容属于受控访问，不能混同为外部泄露。
9. 关键账号/权限、连接和资料配置、资料访问与预览、调研执行、共享/导出及证据/报告变更，无论成功或失败，均记录必要的操作者、资源、结果和时间。个人所有者可读自己的空间审计，项目负责人可读该项目审计；平台管理者可读账户/服务事件，但不能因此读取其他人的项目数据审计。审计接口本身须授权，记录不包含正文或秘密。

边界验收覆盖平台发起的模型、工具、辅助请求和分享。不会承诺阻止用户在平台外手动复制、拍照或自行转移内容。

## 9. 模型连接行为

- 支持 GPT 官方接口及可配置的兼容接口，用户可在其被授权的连接中选择模型；提供商、地址和模型名可配置，不写死某个具体 GPT 版本。
- 只有有配置权限的账号可设置或更改连接及凭据。普通项目成员可选择已获授权连接，不能读取密钥、替换可信地址或修改服务级数据边界。登录响应或运行时会话凭据不包含模型/来源密钥；授权配置者输入的密钥不在保存后回显明文。
- 配置状态、可用性检查、模型不支持当前能力、认证失败、限流、超时与服务不可用区分显示；错误不泄露密钥或私有内容。
- 连接选择成为运行记录的一部分。用户明确选择的连接不存在、失效或能力不足时停止相应步骤，不静默改用其他模型或全局默认；已有结果保留。
- 无可用模型时仍可检索/导入、手工整理证据和浏览资料；依赖模型的生成步骤提示配置需求。

## 10. 双端会话、执行与恢复

- 桌面与 Web 登录同一身份并连接同一受控服务，读取同一会话、运行记录、证据与报告修订。授权和数据策略由共同服务执行。
- 首版桌面以当前 Windows 环境验收；Web 在当前可用桌面浏览器验收。其他桌面操作系统不声称已测试，具体包装与部署方案由 Plan 给出。
- 一个会话同时只有一个调研执行体。同一用户在另一端提交时，不覆盖当前运行；告知已有执行，允许查看或取消后再发起新运行。首版不提供同一段文字的实时协同编辑。
- 运行至少显示当前步骤、完成来源数、已有产物与进行/完成/失败/取消/中断状态。每个终止状态保留必要诊断和已持久化结果。
- 取消后停止发起后续操作；对已发出的请求尽力取消，返回结果不得把已取消运行重新变成完成或覆盖用户修订。取消不承诺追回已发生的外部费用。
- 客户端断连不等于取消。重新登录/连接后读取服务端状态及遗漏事件对应的当前结果，不重复生成已有证据或报告。
- 服务重启后，没有仍存活执行体的未完成运行标为中断。用户可选择重试未完成步骤；已完成来源和产物复用，不能把历史恢复称为自动完成了中断工作。
- 重新执行生成新运行记录并保留旧记录。副作用不明确的步骤不能无条件重放；用户修改与新生成产物发生冲突时保留双方版本。

## 11. 异常与空状态

| 场景 | 用户可观察的行为 |
| --- | --- |
| 未登录、过期或账号停用 | 拒绝后续内容访问，提示登录或联系管理员，保留尚未提交的本端文字但不继续操作 |
| 非成员或移除成员 | 拒绝目标资源和后续事件，不通过错误暴露其他人的资料路径/内容 |
| 来源不明或私有材料加入云端 | 发请求前拒绝，保留选择并说明数据范围冲突 |
| 检索无结果 | 显示空结果，可修改查询或导入论文 |
| 检索失败/限流 | 显示来源步骤错误，保留已有结果，允许明确重试 |
| PDF 超限/损坏/扫描/加密 | 显示未读取原因，不生成假的证据或正文 |
| 只有摘要 | 明确降级为摘要读取，不将缺失信息填成全文事实 |
| 证据缺失/引用失效 | 保存为草稿或待核对，不能标为已校验/已审阅 |
| 目录离线/无权限/文件消失 | 显示对应状态，其他入口可继续使用 |
| 模型缺失/超时/能力不兼容 | 停止生成步骤并保留结果，允许配置后重试，无静默连接回落 |
| 修订冲突 | 拒绝过期覆盖，保留用户待提交文字并提示刷新核对 |
| 取消/客户端断连/服务重启 | 分别呈现取消、继续执行或中断，不混成完成状态 |
